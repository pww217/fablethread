## 1. Convergence Stall for Stealth-Heavy Personas (MEDIUM)

zombie-survival / cautious convergence score drops to 0 for T23-25 (RISING phase with no thread, depth, beat, or dice contribution). The stealth-heavy persona avoids conflict, starving all 5 convergence components.

**Evidence (zombie-survival / cautious 25t):**

| Turn | Score | Phase | Components |
|------|-------|-------|-----------|
| T22 | 1 | RISING | beat_streak=1, rest=0 |
| T23 | 0 | RISING | all 0 |
| T24 | 0 | RISING | all 0 |
| T25 | 0 | RISING | all 0 |

**Root cause analysis:** The convergence system (`_pacing.py:compute_convergence_score`) is **entirely reactive** with no proactive pressure injection. When the player avoids conflict (stealth-heavy play), all 5 components drop to 0 and nothing pulls them back up:

1. **no_urgent_threads** — Storyteller isn't escalating threads to `urgent`
2. **no_active_threat** — Only threat thread is `dormant=True`
3. **fresh_scene** — Scene age = 0
4. **no_beat_streak** — Only 1 beat in T23 (revelation), null in T24, 1 beat in T25 (pressure)
5. **no_dice_weight** — Ruling says "no check required" for stealth/investigation actions

**Impact:** Game state becomes static for 3+ turns. The phase machine waits for `convergence >= threshold` but has no proactive mechanism to inject pressure when convergence is 0.

**Note:** Roadmap ticket `roadmap/bugs/convergence-starvation.md` already describes this issue with suggested fixes (proactive pressure injection, convergence floor, thread urgency escalation). This eval confirms the issue persists.

## 2. Duplicate Condition Adds (LOW)

The state extractor attempts to add conditions that already exist in state.

| Pack | Turn | Condition |
|------|------|-----------|
| golden-piracy 25t | T12 | `winded` |
| golden-piracy 25t | T18 | `bleeding_wound` |

**Impact:** Low. The system correctly ignores duplicate adds. Indicates the extractor doesn't check current conditions before adding.

**Fix:** Add current conditions to state extractor prompt context or add pre-validation that skips condition_add for existing conditions.
