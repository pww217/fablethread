# No-roll turns get outcome summary in player window

## Status
`completed`

## Phases
1 phase: Add outcome summary display for non-rolled turns in the player window.

## Issue
No-roll turns (`ruling.rolled == False`) render no outcome summary — neither on server-rendered page load nor in the live JS streaming path. The `outcome_summary` string is generated by the storyteller extraction stream for every turn, but it's dropped before reaching the UI because:
1. `turn.py` only stores `outcome_summary` in `ruling_event` when `rolled == True`
2. `routes.py` does not pass `outcome_summary` in the `turn_complete` SSE payload
3. The template/JS both skip rendering entirely when `ruling.rolled` is false

## Solution
Thread `outcome_summary` through for non-rolled turns on all three paths (persist → SSE → render). Display a compact grey-background box (matching `.roll-badge` aesthetic but thinner) containing only the outcome summary text below the narrative.

## Firm decisions
1. `outcome_summary` is always stored in `ruling_event` regardless of `rolled` status
2. `turn_complete` SSE includes a top-level `outcome_summary` field
3. New CSS class `.roll-outcome-only` — same `bg-elevated` background + border as `.roll-badge`, but compact padding, no flex-col gap
4. No header/skill/math/band — just the italic summary text
5. Both server-rendered (page load) and JS-rendered (live turn) paths get identical treatment

## Non-goals
- No changes to the turn viewer (TV)
- No changes to rolled turn rendering

## Risks, Ambiguities, and Blockers
None.

## Implementation — Phase 1: Wire outcome summary for no-roll turns

### Context files to load

### Detailed steps

#### Step 1.1 — Store `outcome_summary` for no-roll turns

**File:** `ccya/engine/turn.py`

**What:** Remove the `if _outcome.rolled:` guard so `outcome_summary` is always written into `ruling_event`, not just for rolled turns.

**Why:** `events.jsonl` is the persistence layer that feeds both page reload history and the turn viewer. Without this, no-roll turns lose the summary on reload.

**Validation:** `grep -n 'outcome_summary' ccya/engine/turn.py` confirms the field is set unconditionally.

#### Step 1.2 — Include `outcome_summary` in SSE payload

**File:** `ccya/server/routes.py`

**What:** Add `"outcome_summary": result.outcome_summary` to the `turn_complete` JSON payload (after line 184).

**Why:** JS needs it to render the no-roll outcome box.

**Validation:** Code review.

#### Step 1.3 — CSS for no-roll outcome block

**File:** `ccya/static/app.src.css`

**What:** Add `.roll-outcome-only` rule immediately after `.roll-outcome` block (line 1646). Same `bg-elevated` background + `border-subtle` border as `.roll-badge`, but tighter padding (6px 12px), no flex-col gap, italic text at 11px.

```css
.roll-outcome-only {
  margin: 6px 0 12px;
  padding: 6px 12px;
  border-radius: 6px;
  background: var(--bg-elevated);
  border: 1px solid var(--border-subtle);
  font-size: 11px;
  font-style: italic;
  color: var(--text-muted);
  font-family: var(--font-sans);
  line-height: 1.4;
}
```

**Why:** Visually matches `.roll-badge` weight but is compact since it has no header/math/band lines.

**Validation:** `make check`.

#### Step 1.4 — Server-rendered template for no-roll outcome

**File:** `ccya/templates/index.html`

**What:** Add an `elif` block after the `{% if ev.ruling and ev.ruling.rolled %}` check (line 115):

```jinja
{% elif ev.ruling and ev.ruling.get('outcome_summary') %}
<div class="roll-outcome-only">{{ ev.ruling.outcome_summary }}</div>
```

Place it right before `{% endif %}` closing the roll-badge block (line 142), inside the same narrative-block.

**Why:** Page reload shows the outcome summary for past no-roll turns.

**Validation:** Visual check after reloading a game with no-roll turns.

#### Step 1.5 — JS rendering for live no-roll outcome

**File:** `ccya/templates/index.html`

**What:** In the `turn_complete` handler (line 1378), extend the roll badge conditional to also handle no-roll outcome:

Change:
```
if (result.ruling && result.ruling.rolled) {
    const rollBadge = _buildRollBadge(result.ruling);
    if (rollBadge) { lastInserted.after(rollBadge); lastInserted = rollBadge; }
}
```

To:
```
if (result.ruling && result.ruling.rolled) {
    const rollBadge = _buildRollBadge(result.ruling);
    if (rollBadge) { lastInserted.after(rollBadge); lastInserted = rollBadge; }
} else if (result.outcome_summary) {
    const outcomeDiv = document.createElement('div');
    outcomeDiv.className = 'roll-outcome-only';
    outcomeDiv.textContent = result.outcome_summary;
    lastInserted.after(outcomeDiv);
    lastInserted = outcomeDiv;
}
```

**Why:** Live non-rolled turns show the outcome box immediately.

**Validation:** Play a no-roll turn, observe outcome box appears below narrative.
