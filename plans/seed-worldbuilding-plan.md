# Plan: Seed Worldbuilding Redesign

**Derived from:** [03-Seed Worldbuilding Redesign](../design/03-seed-worldbuilding-redesign.md)
**Depends on:** [Primitives Plan](./primitives-plan.md), [Arc System Plan](./arc-system-plan.md)
**Date:** 2026-06-23

---

## Purpose

Implement seed funnel ordering, pc.situation, arc_origin, key locations, and world state lifecycle. This plan assumes primitives (field renames, deletions, TTL strategy, pressure score system) and arc system (lifecycle, thread→world state, storyteller prompts) are already in place.

## Problem

The current seed system reaches turn 0 with a populated `state.yaml`, but the world it establishes is too shallow to feel real. World facts are injected as flat strings with no proximity to the player. The PC's situational context — what they own, who they owe, whether they have a ship — is either absent or buried in free-form bio prose. Arcs have goals but no backstory. The world state grows without bound and degrades in quality over time.

## Scope

Seed funnel ordering, pc.situation, arc_origin, key locations, world state lifecycle, pack update, and documentation updates.

## Out of Scope

- Field renames and deletions (primitives plan)
- TTL strategy (primitives plan)
- Pressure score system (primitives plan)
- pc.situation in ruling context (primitives plan)
- Arc lifecycle changes (arc system plan)
- Thread→world state promotion (arc system plan)
- Storyteller prompt updates (arc system plan)
- Remove completed threads from storyteller's prompt (arc system plan)

## Firm Decisions

- **Funnel ordering.** Generation moves from most global to most specific: world facts → key locations → pc.situation → NPC bonds → arc → PC bio + inventory.
- **`arc_origin` on seed model only.** Generated by seed LLM at turn 0. Lives on seed state model. Never regenerated. Never injected into narrate, storytell, or ruling prompts.
- **`pc.situation` updatable during gameplay.** If vessel destroyed, home burned, crew lost — these facts should be reflected in state.
- **`pc.situation` tiered surfacing.** Full pc.situation feeds seed prompt and early turns. Ongoing prompts receive only fields marked `persist: true`.
- **`pc_situation_schema` in scenario.yaml.** Defined by pack author. 3–5 keys maximum, all `required: false`.
- **`persist` flag.** TBD at implementation time. Pack authors mark keys using a `persist: true` flag (or equivalent) on each `pc_situation_schema` entry.
- **Key locations.** 4–5 named places at game start. Ordered from most accessible to least known. Includes 1–2 breadcrumb locations.
- **World state TTL expiry.** At start of each turn, hard-delete facts where `current_turn >= expires_turn`. No LLM involved. No archive.
- **Sanitizer as world state custodian.** Extended to maintain world state on same cadence as thread sanitization. Returns complete replacement array.
- **Seed-time valence requirement.** Seed prompt must produce at least one `neutral` or `boon` fact across combined global + local world state.
- **Clean break.** No backward compatibility with existing saves or pack schemas.

## Risks

- **Sanitizer extension.** Adding world state authority to the sanitizer is a significant behavior change. The sanitizer already handles threads; adding world state maintenance doubles its scope.
- **Prompt structural changes.** Rewriting seed prompt with funnel ordering changes what the LLM sees and how it generates. This may affect LLM behavior in unexpected ways.
- **Pack update.** The golden-piracy pack needs `pc_situation_schema`, deleted fields removed, and `scene_detail_bundles` expanded. If pack update is delayed, the game runs without pc.situation but should not break.

## Phase 05: Replace `WorldStateFact` model

**Files:**
- `ccya/models/state.py:150-154` — replace `WorldStateFact` with new schema:
  ```python
  class WorldStateFact(BaseModel):
      id: str
      text: str
      tier: Literal["global", "local"]
      permanent: bool = False
      valence: Literal["threat", "complication", "neutral", "boon"] = "neutral"
      expires_turn: int | None = None
  ```

**What:** Replace `WorldStateFact` model with new schema.

**Why:** Old schema (`tier: Literal["permanent", "persistent"]`) is too coarse. New schema adds tier, permanence, valence, and TTL.

**Validation:** `WorldStateFact` has new schema with `tier`, `permanent`, `valence`, `expires_turn`.
