# Security Policy

## Supported Versions

We actively support the latest release on the `main` branch.

## Reporting a Vulnerability

Please report security vulnerabilities via [GitHub Security Advisories](https://github.com/pww217/fablethread/security/advisories/new).

Do **not** open a public issue for security concerns.

## What to Expect

- You'll receive an acknowledgment within 48 hours
- We'll share our assessment and fix timeline within 7 days
- We'll keep you updated on progress through the advisory process
