# Release 0.10.0

Released: 2026-05-26

## 📋 Summary

This release includes: Add presence/notes/first_seen_turn to compendium models, v1→v2 migration, add ev.py pacing subcommand and search support for momentum fields, write momentum_before/after/delta into every event (not just roll turns); swap directive for summary in TV.

## ✨ What's New

- npc-consolidation-p01: Add presence/notes/first_seen_turn to compendium models, v1→v2 migration
- add ev.py pacing subcommand and search support for momentum fields
- write momentum_before/after/delta into every event (not just roll turns); swap directive for summary in TV
- feat(tv): add pacing_context.summary to Pacing Context section
- fix(tv): add empty op span to pacing context rows for correct grid column placement
- phase-03-pacing-system-overhaul: collapse ages to scene_age, new directives, beat carryover fix, consecutive pressure counter
- phase-02-arc-thread-key-dedup-and-narrator-exposure: add ArcThread.key field, auto-merge dedup gate, expose thematic_question to narrator
- outcome summary for no-roll turns + TV + seed refactors
- feat(turn-viewer): add seed metadata persistence and initial game state display in turn viewer
- Add campaign arc to storytell prompt, fix whitespace, remove duplication
- standardize debug logging across engine and add defensive coercion for stale state
- pool-based pre-selection for dynamic seed generation (Phase 1-4)
