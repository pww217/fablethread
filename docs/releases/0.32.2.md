# 0.32.2

Released: 2026-07-21

## Summary

Patch release fixing condition TTL, urgency decay, compaction quality, and convergence smoothing. Also includes prompt audit fixes for pack generation, NPC naming, and beat system field binding, plus cleanup of dead code and eval infrastructure improvements.

## Highlights

- Condition TTL and urgency decay fixed — conditions now expire correctly, dormant threads decay as designed
- Two-way sanitizer working — urgency escalation and reactivation patterns confirmed across all packs
- Compaction quality gate improved — concrete rules (2-entry minimum, entity preservation) prevent data loss
- Smoothed convergence applied to all phase transitions

## Mechanical Changes

- **B-50.1**: Fixed condition TTL — conditions now respect their `turns_remaining` and expire correctly
- **B-50.2**: Two-way sanitizer — urgency can escalate AND decay based on narrative evidence
- **B-50.5**: Compaction quality gate — concrete rules prevent entity loss during thread compaction
- **B-50.6**: Urgency decay fires independently on untouched threads
- **B-51**: Smoothed convergence score used for all phase transitions (was only used in some)
- **I-43**: Dropped `npcs` field from beat pipeline, strengthened cross-NPC blend guidance
- **I-42**: Removed curtain call mechanic from codebase

## Prompt Fixes

- **Pack generation**: Changed output format from JSON to YAML, added currency fields to schema
- **Narration**: Fixed behavioral drivers (Bond→Tie, added Bio), added explicit name pool directive
- **State extraction**: Added `canonical_id` to InventoryItem model, updated `inventory_remove` schema
- **World**: Bound NPCs to psychological fields in beat effect tags, removed `[environment]` mechanism tag
- **I-2**: Removed dead boundary fields (`RulingBoundary.scene_phase`, `NarratorBoundary.ages`)

## Bug Fixes

- **B-50**: All 6 findings resolved (TTL fix, two-way sanitizer, compaction quality, decay independence)
- **B-51**: Convergence score now uses smoothed values consistently

## Eval / Tooling

- Eval workflow: ticket-as-memory, checkers as bellwethers, ev-review integration
- Added beat system deep-dive to E-18 eval
- Simplified AGENTS.md tickets-as-memory section, removed EV-specific details
