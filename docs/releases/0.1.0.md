# Release 0.1.0

Released: 2026-06-26

## Summary

Initial release: LLM-powered choose-your-own-adventure game with Expanse setting.

## What's New

- Add ccya — LLM-powered choose-your-own-adventure game (Expanse setting)
- Full implementation of a local-LLM text adventure engine backed by Ollama
- Built on FastAPI + HTMX + Alpine.js + Tailwind
- Two-call pipeline: streaming narrate (call 1) + structured JSON extract (call 2)
- Pydantic schema validation with single auto-retry and error feedback
- StateDelta includes scene_tags, present_npcs (NpcRef)
- Quest create-or-update semantics fixed
- apply_delta: auto-clears present_npcs on location change, persists scene_tags
- extract_num_ctx matches num_ctx to prevent Ollama model reload between calls
- enforce_extract_schema flag (default off)
- log_llm_io flag — full prompt/response payloads logged at DEBUG level
- established_facts_max bumped to 25
- Extract prompt: explicit quest resolution instructions
- Extract prompt: present_npcs and scene_tags field guidance
- Narrate prompt: instructs LLM to make quest resolution explicit in prose
- Opening scene: Expanse universe (Ceres, Belter smugglers, the Wretch)
- Belter slang glossary removed from opening scene
- Setting pack: expanse-belter
- Captain Niko Sato aboard the Wretch, Ceres Station Lower Levels Market
- Crew: Davi Moreau-Ng (pilot, ex-MCRN) and Sigge Petrescu (enforcer)
- Seed state includes ~25 established facts
- Opening scene server-rendered at turn 0; persists across refreshes
- New Game triggers page reload
- Markdown rendered everywhere
- Scene card: NPCs shown as named cards
- Facts scroll box: shows latest 7 facts; count badge shows total
- 4 action pills per turn
- Debug sidebar card
- No auto-open browser on startup
