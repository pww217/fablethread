# Release 0.29.0

Released: 2026-06-26

## 📋 Summary

This release delivers a major overhaul of the game's core mechanics and tooling. The arc system gets a complete redesign with semantic thread types, dormant urgency, and convergence scoring. Beat generation is split into focused steps. The eval system is rewritten with new skills, checkers, and workflows. The project's workflow moves from Linear to a self-tracking roadmap.

## ✨ What's New

- Arc system redesign with semantic thread types, dormant urgency, auto-dormant, and culling
- Convergence scoring overhaul: type/dormant-aware, SETUP TTL, proactive pacing, threshold lowered from 3→2
- Effect-driven, NPC-first beat system replacing storytell-generated beats
- Scene-driven beat generation replacing storytell-generated beats
- Replaced candidate_npc_ids+effect with candidate_npcs in GM beats
- Removed personality from beat types, added type-specific effect templates
- Redesigned pc_situation_schema per-pack, lower temperature, added arc_origin, two-step design
- Re-introduced TTL-based auto-expiration for player conditions
- Per-NPC party flag exempts companions from auto-demotion on location change
- Distinguishing descriptors for group NPCs via prompt guidance
- Enforced individual-unit quantities for all consumables across seed and extractor prompts
- Added presence field to slim NPC roster in storytell
- Reworked scene extractor to output psychological state hints instead of beat-like effects
- Use surnames for location names, full names for NPCs
- Arc System, Primitives, Seed Worldbuilding full refactor
