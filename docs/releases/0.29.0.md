# Release 0.29.0

Released: 2026-06-25

## 📋 Summary

This release includes: Consolidate disk writes, rename state_snapshot→last_turn_state, simplify cancel, add progressive SSE, Re-introduce TTL-based auto-expiration for player conditions, redesign pc_situation_schema per-pack, lower temp, add arc_origin, two-step design.

- [deferred-state-persist]: Consolidate disk writes, rename state_snapshot→last_turn_state, simplify cancel, add progressive SSE
