# Release 0.17.0

Released: 2026-06-08

## 📋 Summary

This release includes: decoupling threads vs arcs (DQ03), bonds generating arc objectives at start (F-I09), left-behind NPC tracking on location change (F-N07), move F-N06 to Scene Mechanics section, Add thread sanitizer design doc and implementation plan.

## ✨ What's New

- add missing items + fix structure: decoupling threads vs arcs (DQ03), bonds generating arc objectives at start (F-I09), left-behind NPC tracking on location change (F-N07), move F-N06 to Scene Mechanics section
- Add thread sanitizer design doc and implementation plan

## 🔧 Engine Changes

- condition-difficulty: Replace CONDITION_MODS with LLM-driven difficulty adjustment via reason field
- fix PRIORITIES.md cross-ref: F4 now points to FEATURE-IDEAS instead of BUGS-OBSERVATIONS
- organize findings: move features out of BUGS-OBSERVATIONS into FEATURE-IDEAS by subsystem
- fix(scene-extract): allow deriving new location IDs for location_change from narration context
- thread-lifecycle-engine-fixes: urgency decay + scene-scoped expiration enforcement
- Update repomap to reflect floor relief momentum guard and scene imperative threshold change
- Update architecture docs to reflect momentum-thread-goal-fixes implementation changes
- fix(turn.py): remove broken auto-latent demotion timestamp reset loop (Step 01.3a)
- phase-02-sanitizer-fixes: thread cleanup (#5) + goal pivot (#3) sanitizer prompt updates
- phase-01-momentum-fixes: momentum systemic fixes (MB-1 through MB-7)
- findings: update CONTENTS.md routing — all game findings to FINDINGS-JUNE-6.md, remove stale references
- Fix B1, MB-5, B3: inventory prompt, pressure counter source, remove sanitizer removed_threads
- sanitizer TV collapse: use s- prefix key to avoid collision with normal turns
- sanitizer delta: capture before/after in changes_detail, flatten to diff-row in TV
- sanitizer: remove dead summary field loop after ThreadUpdate loss
- Annotate sanitize_every: 0 = disabled in config snippets
- Fix orphaned World state section and delta-validate diagram
- Code review fixes: legend position + pre-existing thread-noise cleanup
- Reduce noisy arc/thread updates: ProgressEntry, dedup, auto-latent, cap, resolved_arcs, prompt tightening
- prompt diet, wipe npc.notes between turns
- cleanup some docs, tweaks to storytell_system

## 🎨 UI Changes

- threads: remove summary from ThreadUpdate, tighten progress and choice guidance
- thread-sanitizer: batch arc/thread cleanup module + pipeline hook + frontend
- Remove direct world_state writes from LLM pipeline; tighten prompt guidance
- Fix char creation budget to 10pts; scale sidebar text consistently across all non-laptop viewports; reduce tooltip sizes; clamp location name/description font sizes with pixel bounds so they don't inflate on ultrawide
- ui: increase non-mobile font sizes by ~30%, ultrawide sidebar 2x default, sidebar text overrides; fix location panel hardcoded px fonts; add reset sidebars button with viewport-aware defaults and auto-adjust on resize
- ui: replace single clamp() with 3-tier @media font-size scaling
- fluid-ui-sizing: bump desktop base font size by ~25%

## 🛠️ Eval & Tooling

- ev tooling: port ev.py into ccya/ev/ package (plan 01)
- fix(eval): model config, judge timeout, pynocache race fix, B13 consecutive_pressure counter
- fix(eval): correct three off-by-one false positives in auto-checker assertions
- baseline-eval: compare findings against 2026-06-07T073432Z run, add scoring context and cross-game confirmations
- Implement dual-track eval: baseline track for aggregate gameplay quality
