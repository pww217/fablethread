# Release 0.33.0

Released: 2026-07-16

## Summary

This release delivers significant improvements to LLM fallback reliability (dropping detection from 22s to 7s), adds two new eval checkers for pacing and convergence, and fixes the single-location persistence issue that prevented scene directives from firing reliably on same-location runs.

## Highlights

- **Faster LLM fallback** — Connection timeout reduced 10s→3s, retry delay 2s→1s, cooldown 300s→30s. Plus `openai.APIConnectionError` is now correctly treated as retryable.
- **Scene directive location fix** — Scene imperative/pressure directives now track by `location_entered_turn` instead of `turn_entered`, so they fire when the player stays in one location across multiple phases.
- **Two new eval checkers** — `convergence_threshold_context` verifies gating thresholds use configured values; `turns_in_phase_counter` validates phase counting monotonicity.
- **Arc resolve lifecycle checker** — New comprehensive checker for arc goal/thread transitions on arc_resolve, plus fixes for `None` slicing in existing code.

## Mechanical

- Track scene directives by `location_entered_turn` instead of `turn_entered` (pacing fix)
- Add `location_change_reason` field to extraction pipeline (required on location transition)
- Add `APIConnectionError` to `_is_retryable()` — fallback host triggers on connection failures
- Reduce `_make_httpx()` connect timeout from 10s to 3s
- Reduce fallback retry delay from 2s to 1s (both sync and stream paths)
- Reduce `fallback_cooldown_s` default from 300s to 30s — easier primary/fallback swapping
- Add `convergence_threshold_context` checker (validates RISING→CLIMAX and CLIMAX→RESOLUTION gates)
- Add `turns_in_phase_counter` checker (validates monotonic phase counting, reset on phase change)
- Add `arc_resolve_lifecycle` checker (validates arc goal/transition carried to new arc after resolution)
- I-41: Create tracker for EV checker coverage gaps (EMA, thresholds, culling, arc resolve, turns_in_phase)

## UI / Frontend

- Fix sidebar character list: `nearby_npcs` undefined variable → `_present.nearby_items` everywhere
- Sync state-left panel on record extraction instead of waiting for async window (consolidated with async panel refresh)

## Eval / Tooling

- Two new deterministic checkers added to eval suite
- I-41: New ticket tracking EV checker coverage gaps (EMA, thresholds, culling, arc resolve, turns_in_phase)
- E-13: Narrative & pacing deep-dive across 5 packs — noir-verif 25t, all engine fixes verified working

## Bug Fixes

- Arc resolve lifecycle: prevent `None[:60]` crash on old_goal slicestructures when `None`
- Arc resolve lifecycle: prevent `sorted([...set of thread IDs...])` crash when IDs contain `None` values- Narrate: fix `_narrate_setup` return type — was `tuple[Any, Any, Any]` but returns 4 values
- Pacing: fix single-location persistence (scene directives not firing after phase transitions)
