# 0.33.0

Released: 2026-07-30

## Summary

This release introduces significant improvements to NPC management, engine reliability, and the evaluation tooling. Key additions include split NPC Add/Update operations with disposition tracking, location expansion design consolidation, and a complete rewrite of default pack seed pools with per-entry archetypes subversion. The engine also gets a major tech debt cleanup addressing typing, function sizes, and silent failures.

## Highlights

- **F-30: Split NPC Add/Update ops** — New disposition field for NPCs, cleaner separation between adding and updating NPC entries in the compendium
- **I-42: Name pool compliance** — Seed and turn name pools now enforced consistently across all packs; new characters always use assigned names from the roster
- **I-43: Pack archetypes subversion** — All 5 default pack seed pools rewritten with per-entry subversion for more interesting starting scenarios
- **I-44: Pre-stream progress bar** — New UI shows TTFT for ruling + narrate phases, extraction row de-wrappered for cleaner display
- **Eval fixes** — 5 checker fixes: convergence, location, thread urgency, ruling word count, and name pool

## Mechanical Changes
