# Release 0.33.0

Released: 2026-07-17

## Summary

Health probe system to detect unhealthy primary LLM before attempting inference, preventing indefinite extraction hangs. E-13 completes noir verification across 5 packs with engine and checker fixes. Cleanup of llama-swap references and stream naming.

## Highlights

- **Health probe system** — `/health` endpoint check with 30s cache prevents inference hangs when primary responds to health but inference endpoint is unresponsive
- **E-13 noir verification** — 25-turn eval across 5 packs with engine fixes for beat_candidates dead end and checker false positive reductions
- **llama-swap removed** — All references removed from code and docs; LLMStudio set as primary LLM

## Mechanical Changes

- Add `/health` probe with 30s per-host cache in `llm_client.py` — `_check_health()` probes primary before inference, skips primary if unhealthy
- Engine fixes for Noir T12-T15 `beat_candidates=[]` dead end — E-13 engine patches
- Update World prompt to match `recent_beats_max=4`
- Persist `smoothed_convergence` in state — B-46
- Add `arc_resolve_lifecycle` checker, update thread culling logic — B-45
- Thread urgency decay exempts dormant threads from `urgency_max_age` check

## UI / Frontend

- Refresh state-left panel after record extraction instead of waiting for async window

## Eval / Tooling

- E-13: Noir verification 25t across 5 packs (noir-1930s, zombie-survival, space-western, piracy, medieval)
- E-13: Checker fixes — `beat_candidates_present` allows empty beats with `post_turn_pending_beat`, `location_change` relaxed for redundant deltas, `thread_urgency_decay` exempts dormant threads
- B-45: Fix `extraction_retry_rates` checker showing misleading per-turn output
- B-44: Restore ev.py persona presets with persona naming (aggressive, cautious, absurd, explorer, driven, opportunist, completionist, speedrunner, custom)
- I-40: Complete `storytell`→`record` stream name cleanup across codebase
- B-49: Fix `prompt_eval` using `EngineConfig()` defaults (empty fallback_host) — now uses `build_engine_config(load_config())`

## Bug Fixes

- B-49: Extraction hang — primary `/health` returns 200 but inference endpoint hangs; SDK timeout doesn't enforce connect timeout — fixed with health check before first attempt + `httpx.Timeout(connect=5.0, read=timeout)`
- B-44: `ev.py personas` command required events file — fixed to work without events
- B-46: Fix `beat_narrative_chain` checker

## Documentation

- E-13: Document Phase 4 run configuration (endpoint, model, fallback)
- I-13: Add closure section with pre/post-fix skill distribution data
- B-49: Bug ticket documenting prompt_eval config and extraction hang issues
