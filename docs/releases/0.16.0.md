# Release 0.16.0

Released: 2026-06-06

## 📋 Summary

This release includes: Add restraint examples for thread_update and world_state in storytell_system.j2, add npc-personality plan, Add per-call top_p, frequency_penalty with nested config structure.

## ✨ What's New

- Add restraint examples for thread_update and world_state in storytell_system.j2
- plans: add npc-personality plan
- sampling-params: Add per-call top_p, frequency_penalty with nested config structure
- Add arc thread cleanup plan and LLM findings from review

## 🔧 Engine Changes

- engine_mirror: import PRESSURE_BEAT_TYPES from turn.py and derive GM_BEAT_TYPES from GMBeat Literal annotation
- block phantom inventory removals at validation time (turn.py)
- Remove broken npc_mention assertion, fix thread timing bug, remove scene_tags assertions
- fix-floor-relief-override: move injection pre-apply_delta to fix deep-copy propagation bug
- Force Scene Imperative directive to produce outcome_hint=transition; clarify thread summary vs progress usage
- seed: tighten active thread and urgency limits to prevent over-generation
- Remove thematic_question and clean up stale thread fields (tags, key)

## 🎨 UI Changes

- fluid-ui-sizing: convert all font sizes to fluid rem units with proportional sidebars
- UI: show labeled stat and difficulty modifiers in roll display
- Show PC stats as gold dots in sidebar panel, matching char creator style
- engine_mirror: replace hardcoded constants with live imports from EngineConfig and delta_builder
- Thread tooltip: render progress as capitalized prose with <p> line breaks
- seed: enforce hard limits on active threads (code-level fix) + tighten world_state guidance
- seed: tighten arc thread limits, require MFL and bonds for present NPCs
- Mobile: hold action pills to fill input without submitting; prevent horizontal scroll in narrative panel

## 🛠️ Eval & Tooling

- cut-to-four-skills: remove lore/resolve, reduce to strength/dexterity/wits/charisma
- Update EVAL-FINDINGS with F4 fix and engine validation audit findings
- Update EVAL-FINDINGS.md with latest run data and mark fixed issues
- move(cut-to-four-skills): approve plan, move review → active
- review(cut-to-four-skills): update plan for 4-skill system, fix ruling_system.j2 scope gap and engine_mirror derivation
- fix(eval): two universal assert bugs — unhashable thread IDs and beat_locked false positives
- fix(eval): handle dict thread_update objects in universal assert check_thread_update_id_valid
- fix(eval): resolve Pydantic validation errors for seed_state.yaml and NPC compendium lookup bug

## 🐛 Bug Fixes

- remove survivor archetype, set max budget to 10 for all presets
- reduce survivor archetype from total 12 to total 10
- set character creation budget to 12 points across four skills
- normalize archetype presets and update char creation UI budget display
- remove remaining shaken references and fix archetype comment accuracy
- surface extraction failures to UI, normalize thread dicts for templates
