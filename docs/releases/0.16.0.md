## Summary

Major release on arc system overhaul, compactor, mobile UI, settings panel, and prompt overhauls.

## What's New

- Arc system: implement Phases 1–4 (full arc/thread lifecycle redesign)
- Add prior_history (last 10 bullets) to storytell extractor context

- Seed-hints-and-cleanup: make player overrides authoritative, wire arc/drive hints, remove quest_hints and 2-item rule
- Dynamic save directories per game
- Impossible action gating + pacing outcome hints
- 2d6 → 1d12 dice system: more variety, fewer middling outcomes
- World-state-history redesign: delete recent_events system, promote world_state to mutable tiered structure
- World State UI: newest-first ordering, remove tier labels, sort persistent first, permanent at bottom
- Fix right sidebar: recreate _state_right.html, move Player card from left to right
- Remove inventory durability gate per Phase 0 design
- Show roll math in narrate_user: d12 + modifiers (skill) = total
- Fuzzy inventory_remove: add fuzzy fallback, suppress missing-item rejections
- Dynamic save directories per game

- UI: replace single clamp() with 3-tier @media font-size scaling
- Fluid UI sizing: bump desktop base font size by ~25%, convert all font sizes to fluid rem units
- Show labeled stat and difficulty modifiers in roll display
- Show PC stats as gold dots in sidebar panel, matching char creator style
- Thread tooltip: render progress as capitalized prose with <p> line breaks
- Streaming scroll + action pills scroll-triggered reveal
- Hide action pills until user scrolls to bottom of narrative
- Mobile UI: hide scene tagline, center chronicle pill, reorder header buttons with directional arrows on sidebar toggles
- Turn cancel: server-side cancellation with full state revert
- Make kill and arc emojis
- Auto-resume latest save dir on server restart instead of resetting to saves/default/
