# Release 0.32.0

Released: 2026-07-12

## Summary

This release brings several major features: stacked turn progress cards for the UI, manual party management with inventory drops, automatic difficulty adjustment, and a full pack validation system. It also includes extensive eval-driven improvements to beat generation, NPC tracking, and pacing engine stability across multiple eval cycles.

## Highlights

- **Turn progress cards** — Stacked per-phase progress UI (F-35) replacing the broken ruling card format
- **Manual party management** — Players can manage AI party members and drop inventory items (F-29)
- **Auto difficulty adjustment** — Difficulty auto-adjusts based on matching stats (F-34/I-34)
- **Pack validation system** — Baseline validation for packs with in-code and static CLI scripts (F-15)

## Mechanical Changes

- Compendium mid-turn updates with position cleanup
- Beat generation strengthened to require at least 1 candidate
- Recent_beats persistence fixed across engine runs
- Thread diversity tightened: 5-beat window, ban repeats of 2+ times
- Thread urgency, GM beat TTL, location delta, and seed prompt fixes (B-38/B-39/B-40/B-41)
- Thread creation cooldown removed, culling threshold raised to ≥4 dormant
- Beat recipe format with NPC personality priority and 20-word effect hint limit
- Difficulty adjustment serialization (difficulty_adjustment + original_difficulty in ruling event)
- Pacing convergence score accumulation fixed
- Thread lifecycle restructured: Record vs Narrator prompt ownership
- NpcPresence enum standardized (NEARBY for new entries)
- Seed turn restored as turn zero; seed meta enforced from config
- Tie field disambiguation in seed prompt; PC/player references removed

## UI / Frontend

- Stacked turn progress cards with per-phase expected_ms and exclusion bars
- Extraction row simplified from ruling card / progress card to single extraction bar
- NPC panel handler aligned with card name rename; stale HTMX fetch removed
- NPC sidebar deterministic per-NPC colors (I-17)
- NPC sidebar rendering fix with toggle race guard and seed row ordering
- Model shown in seed row header; seed and game state blocks visible
- PC situation fields moved from Name tooltip into player panel rows
- Pgeom sidebar toggle active class added; banned phrase added to narration
- State-left panel refreshes after record extraction instead of waiting for async window
- Seed row prompt cleaned: scene bundles and location.description removed from narrate_seed, pc_situation emphasized

## Eval / Tooling

- E-11: Fresh full eval cycle (archival-noir, golden-piracy, zombie-survival, allied-ww2) — NPC management deep dive, beat/NPC behavior verified
- E-12: Convergence starvation review
- E-13: Phase 2/3 stability eval with easing diversity bans, thread decay seeding, ruling tightening
- Eval golden-piracy 20-turn run: pass rate 87.2%
- 9 dead/failed eval groups removed
- EV checker beat_streak logic corrected to match engine logic
- Checker fixes: arc → long_term_objective rename for thread and sanitizer lifecycle
- Pack validation CLI script validated (validate_packs.py)
