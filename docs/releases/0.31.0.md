# Release 0.31.0

Released: 2026-07-03

## Summary

This release covers ~70 commits since 0.30.0, spanning a major architectural shift to LMStudio as the primary LLM backend, the WorldState model migration, a comprehensive pacing redesign, and the PC situation schema system. It also includes 17 new deterministic checkers, workflow improvements for the ticket/eval system, and numerous bug fixes across the engine and UI.

## Highlights

- Migrate primary LLM backend from Ollama/LMStudio dual to LMStudio-only
- Complete WorldState model migration (I-17, Phases 01-05)
- Pacing redesign: spiral removal, convergence scoring overhaul, hysteresis + phase minimums
- PC situation schema: typed model with persist flags, filtered surfacing in ruling/narrate
- Split Storytell into Record + Ruling beat selection + async World step
