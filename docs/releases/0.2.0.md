# Release 0.2.0

Released: 2026-05-03

## 📋 Summary

This release includes: overhaul turn viewer, stabilize prompts, reduce token budgets, add turn viewer for inspecting full pipeline prompts and responses, add per-pipeline timing and token counts to debug panel.

- overhaul turn viewer, stabilize prompts, reduce token budgets
- add turn viewer for inspecting full pipeline prompts and responses
- add per-pipeline timing and token counts to debug panel
- fix player intent comprehension, scene proximity, and NPC naming
- add outcome_summary to roll badges, colorize turn log lines, enable markdown rendering
- finish Plans B, C, D — reasoning checkpoint, failed feedback, state slicing
- auto-complete quests when all objectives are done
- scope boundaries via rules call enhancement (Plan C)
- label context blocks + merge narrative into extract user message

## 🛠️ Eval & Tooling

- feat(ccya): rules engine, 6-stat system, UI overhaul ## Rules engine (ccya/ccya/rules.py — new) - Pure-Python 2d6 PbtA dice resolver: roll_2d6, compute_band, resolve_check,   conditions_modifier, build_directive, GM_MOVES per band - 5-band outcomes: crit_fail (snake eyes), fail (≤6), mixed (7–9),   success (10–11), crit_success (boxcars) — crits override modifiers - Modifier stack: (stat_value−2) + difficulty_mod + condition_mod - CONDITION_MODS map (wounded/exhausted/drugged/frightened/shaken/bleeding) - Deterministic with seeded RNG for tests; 40 unit tests in test_rules.py ## Three-call turn pipeline (engine.py) - Call 0 (rules/intent): fast non-streaming LLM classifies player intent and   whether a dice roll is required; returns IntentEnvelope JSON - Python resolves dice deterministically after LLM returns intent - Graceful degradation: parse failure → no-roll, pipeline continues unchanged - rules_start / rules_done phase SSE events emitted with full roll payload - rules block added to events.jsonl and TurnResult for logging/UI ## New Pydantic models (models.py) - SkillName, Difficulty, Band literals - RulesCheck, IntentEnvelope, RulesOutcome models - rules field added to TurnResult dataclass ## Narrator binding (narrate_system.j2) - Conditional BINDING block injected when rolled=true: skill, dice math,   band, directive — narrator must not contradict the result - Compound-action rule: narrator stops the chain on fail/crit_fail ## Extractor hint (extract_user.j2) - Rules outcome hint block prepended: intent_verb, band, guidance on which   state changes to apply per band (no quest completion on fail, etc.) ## Unified 6-stat schema - Canonical stats: strength, dexterity, wits, lore, charisma, resolve - state.py _migrate_state maps old 4-stat schema (body/mind/tech/social)   and fills missing stats at default 2 - _default_state initialises all 6 stats - All 8 pack scenario.yaml: pc_stat_total_range updated to [12, 18] - expanse/seed_state.yaml rewritten with new stat keys - pack.py Constraints default bumped to (12, 18) - generate_seed_system.j2: explicit 6-stat definitions added ## Rules prompts (new files) - prompts/rules_system.j2: skill list, 5 difficulties, default-NO 3-of-3   stakes rule, anti-declare-outcome guard, compound-action handling - prompts/rules_user.j2: PC stats + recent turns + current input ## Config / server wiring - config.yaml: rules section (temperature: 0.2, max_retries: 1) - EngineConfig: rules_temperature, max_rules_retries fields - server.py: wires rules config fields; passes result.rules in turn_complete SSE ## UI - Roll badge (3-line): skill+difficulty header, labeled dice math, color-coded   band pill — appears AFTER narrative renders (not before) so player reads   story first; also shown in "What changed" modal and Chronicle log - Progress strip: "Determining Outcome" (rules_start), "Updating Game State"   (extract_start, was "Processing outcome") - Stats sidebar: 2×3 CSS grid for 6-stat layout - Location changes split into own 📍 category (was grouped under 🩺 Player)   in both the turn summary modal and chronicle log - Fact truncation removed from format_change_lines — full text always shown - Metrics row includes rules timing alongside narrate/extract ## World-gen improvements (generate_seed_system.j2) - Naming rule: explicitly calls out Anglo-fantasy defaults (Elias Thorne,   Clara Miller) as generic filler; instructs cultural/linguistic sourcing   from setting demographics and invented cultures - NPC constraint line reinforces no-default-Anglo-surname requirement ## Tests - tests/test_rules.py: 40 unit tests covering band edges, condition stacking,   seeded resolve_check, difficulty map, invalid inputs - tests/test_engine_smoke.py: updated _FakeLLM for 3-call pipeline (Call 0   returns no-roll by default); stat migration test added; all 74 tests pass
