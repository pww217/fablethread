# Release 0.28.0

Released: 2026-06-26

## Summary

A focused release on logging infrastructure, condition redesign, and prompt hardening. The structured logging system is completed, the condition system is redesigned with age tracking and change reasons, and ruling/narrator prompts are tightened.

## What's New

- Condition redesign: remove TTL expiration, add condition_change_reason, show age, clarify authority
- Remove PC_CONDITIONS_MAX mechanic — no cap on concurrent player conditions
- Separate thread and arc lifecycle to fix arc-thread conflation
- Ruling: consolidate impossibility + difficulty into single section, tighten impossible threshold
- Ruling: decouple required from difficulty, route shooting to dexterity
- Narrate_user: replace teleportation instruction with active departure for scene transitions
- Instruct all models to use character names instead of PC/NPC labels

## Engine Changes

- NPC: fix design deviations, last_seen tracking, unnamed personality guard (twice)
- NPC: restructure compendium fields — bio split, allegiance removal, departed consolidation
- Engine: remove location-change-to-SETUP phase reset
- Fix: apply character creator stats directly instead of passing as LLM hints
- Restore NPC UI + condition redesign + phase reset (undo revert)
- Fix: deep-dive-report root cause fixes — checkers, audit, scene prompt

## UI Changes

- Capitalize LLM text, add intent tooltips on band pill, fix chronicle tooltips
