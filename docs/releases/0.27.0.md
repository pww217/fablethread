# Release 0.27.0

Released: 2026-06-15

## 📋 Summary

This release includes: directive/spiral beat constraint overhaul, 7 new checkers + prompt fix for location descriptions, Add tension_delta field, scene phase config thresholds, and ruling prompt schema.

## ✨ What's New

- pacing: directive/spiral beat constraint overhaul
- 7 new checkers + prompt fix for location descriptions
- foundation: Add tension_delta field, scene phase config thresholds, and ruling prompt schema

## 🔧 Engine Changes

- fix(npc): hybrid prompt+engine fix for group NPC quantity deduplication
- Unify roll and non-roll outcome badges
- fix(turn): override outcome_hint using effective_scene_age instead of crisis counter
- seed: force at least 1 NPC presence=present in sanitize_envelope
- fix(tension_monotonicity): use state_snapshot.arc instead of arc for thread urgency check
- pacing: remove unused RollRecord TypedDict (dead code)
- Fix entity highlighting: restrict to narrative text only, consume trailing possessives/plurals
- Remove dead code detected by vulture
- scripts/debug: remove 10 dead get-*.sh wrapper scripts
- engine: coerce unknown progress_kind values and relax thread dedup threshold
- prompts: past/future explicit instruct for state extractor
- design doc cleanup

## 🎨 UI Changes

- prompt: require at least 1 NPC with presence=present in seed generation
- css: Replace purple thread delta colors with indigo/gold/gray palette
- Add scene_phase/summary to debug row, ruling reason tooltip, inventory change reason tooltip
- prompt-templates: replace directive→beat table with phase→beat constraints, remove gate rendering, surface scene_phase

## 🛠️ Eval & Tooling

- Linear reorganization: 6-bucket hierarchy, ticket prefixes, parent assignment, and docs update
- ev-tooling: complete remaining plan items - momentum-check command, beat_locked/momentum_floor in pacing, narrate extraction
- fix extraction scene_phase/allowed_beat_types, compendium NPC creation, beat checker
- eval-game fixes: strengthen inventory prompt, fix pacing checker, relax tension checker, filter evicted threads
- ev: surface all new pacing fields in CLI display; fix phase_persistence checker; clean README
- ev checkers: add 5 new phase engine checkers + fix crisis_turn_count bug
- ev-tooling-alignment: Fix phase-persistence bug, add checkers, update docs

## 🐛 Bug Fixes

- add recent_rolls rename to Decision Table + resolve spiral_decay_turns in review-pacing-plan
- correct table separator column count (4→3 dash groups)
- save picker modal hidden on mobile due to nested backdrop
- TICK-28 mobile save picker z-index + TICK-67 storytell inventory names + Blocked status lifecycle
- strengthen prompt directives, add scene_phase to ruling, fix scene_age tracking
- checker logic false positives from new game data
- checker requires_fields to match actual event schema
- phase engine bugs — breather count, enforce_relief order, state_snapshot timing
