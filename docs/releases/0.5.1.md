# Release 0.5.1

Released: 2026-06-26

## Summary

Modular world-pack system with dynamic scenario generation.

## What's New

- Modular world-pack system with dynamic scenario generation
- New pack.py: Pydantic schema-of-record for the entire pack system
- Two pack modes: static (hand-authored) and dynamic (LLM-generated)
- Engine changes: generate_seed(), pack_style/pack_examples kwargs
- Server changes: POST /new-game, POST /new-game/reroll, load_pack()
- UI: pack picker modal, Roll Again button, player_overrides stub
- Packs: expanse-belter (static→dynamic), zombie-survival (new dynamic)
- Established facts quality overhaul: exactly 12 facts, cliche guards
- Prompt rule reorganization in extract_system.j2
- Turn UX: structured changes, turn summary modal, chronicle pill, stop/cancel
- Debug panel: simplified columns, two-line tok in/out
- CSS cache-busting
- Reliable turn flow v4: extract slim, NPC hydration, narrate/extract thinking flags, diff toast UX
- Extract: replace embedded Pydantic JSON Schema with concise TS-style schema
- Extract: 2 new worked examples for quests and inventory
- Thinking: split into two independent flags (extract_thinking, narrate_thinking)
- NPC hydration: NpcRef hydration from compendium saves ~150-250 output tokens/turn
- UI: diff toast 10s with Esc/x dismiss, inline markdown, streaming markdown
- Delta facts, chronicle-canonical narrative, named NPCs
- Two-sidebar UI, quest failure states, fact supersession, Ollama tuning UI/layout
- Split state panels into left/right sidebar layout
- Debug panel redesign: merged errors, recent turns table, concise status
- Quest failure states: failed/abandoned/completed/active
- Established facts management: 25-fact cap, established_facts_remove
- Ollama tuning (Apple Silicon): flash attention, KV cache, parallel settings
- Server/CLI: warmup task, /healthz, OSC 8 hyperlink banner
