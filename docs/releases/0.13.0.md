# Release 0.13.0

Released: 2026-06-03

## 📋 Summary

This release includes: implement all six pacing/beat design changes in turn.py and config.py, add empirical-finding references to three design docs, 'Breathe' directives don't work (pending_gm_beat never cleared when storytell emits null), TTL=2 race conditions confirmed across 17 turns, recommend tearing out TTL entirely.

## ✨ What's New

- core-rewiring: implement all six pacing/beat design changes in turn.py and config.py
- add empirical-finding references to three design docs
- Add GM beat expiration analysis: 'Breathe' directives don't work (pending_gm_beat never cleared when storytell emits null), TTL=2 race conditions confirmed across 17 turns, recommend tearing out TTL entirely
- arc-resolution-redesign — structured successor creation + thread promotion
- Remove dead pack fields and mode infrastructure; add parity gaps for generated packs
- thread: remove key/tags dedup, add progress field
