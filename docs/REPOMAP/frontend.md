# Frontend — CSS, JS, templates

## CSS

- `ccya/static/app.src.css` — source CSS. Edit this.
- `ccya/static/app.css` — generated by Tailwind. **gitignored, do NOT commit.**
- Always: edit `app.src.css` → run `make css` → do NOT commit `app.css`.
- Vendored JS (`ccya/static/vendor/`) IS committed and tracked.

## JavaScript

- No build step, no TypeScript, no npm packages beyond `@tailwindcss/cli`.
- UI logic in `index.html` (Alpine.js `x-data` component + SSE event handlers) and `app.js` (non-Alpine helpers).
- Markdown rendered with `marked.js` via `_renderMarkdown()` / `_renderMarkdownInline()`. Do not add a second markdown renderer.
- Tooltip positioning uses `#tooltip-portal` (fixed, viewport-anchored). Don't use `position: absolute` on tooltips inside overflow-clipped containers.
- Progress phases: `narrate_start → narrate_done → extract_start → extract_retry? → extract_done → persist`. Any new phase must be handled in `_setProgressFromPhase` or it will silently stall the timer.

## HTML templates

Located in `ccya/templates/`:

- `index.html` — Main UI: Alpine.js x-data component + HTMX panels
- `_state.html` / `_state_left.html` / `_state_right.html` — State panels
- `_actions.html` — Action buttons
- `_debug.html` / `_errors.html` — Debug and error panels
- `_pack_picker.html` / `_char_creation.html` — Character creation
- `_turn_log.html` / `_turn_viewer.html` — Turn history/viewer

## Turn Viewer status colors

The standalone turn viewer (`/turn_viewer`) uses semantic status colors from CSS custom properties in `static/app.src.css` (`--status-*`). Stage accent stripes use `--stage-rules`, `--stage-narrate`, `--stage-scene`, `--stage-state`, `--stage-progress`.

| Token | Meaning |
|-------|---------|
| `--status-ok` | Stage ran and completed (no extraction error). |
| `--status-skipped` | Stream elided by scope (`skip_domains` covered all domains). |
| `--status-retried` | LLM output required a parse retry (`attempts` > 1 in event). |
| `--status-rejected` | Post-extract validation rejected part of the delta (e.g. bad `inventory_remove`). |
| `--status-error` | LLM call or parse ultimately failed for that stream. |
| `--status-neutral` | Non-fatal / informational (e.g. rules path with no dice roll). |

Status always wins for the prominent left border over stage accent stripes.
